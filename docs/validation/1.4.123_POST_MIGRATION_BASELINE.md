## 3. Result, implementation status та failure classification

Кожний case зберігає незалежно:
- Result: PASS / FAIL / UNTESTED. PASS лише коли всі named observable acceptance steps виконані; FAIL при відтвореному порушенні або raw test assertion; missing evidence =UNTESTED.
- Implementation status: vocabulary CONTEXT_AND_STATUS (IMPLEMENTED IN SOURCE / STATIC VERIFIED / LIVE VERIFIED / MIXED / DESIGN ONLY / CATALOG ONLY / UNKNOWN).
- Execution disposition: DEFERRED / blocked prerequisite / runnable under authorized task. DEFERRED не є PASS.
- Classification та reason/evidence. Raw FAIL може бути TEST ERROR/stale expectation; це не автоматично gameplay FAIL.

| Classification | Мінімальна доказова умова |
|---|---|
| MIGRATION REGRESSION | Підтверджена втрата approved pre-migration behavior у matching post-migration scenario; old/new DLL SHA, native versions, settings/state, reproduction та відокремлення build/version/test differences. Сам report «раніше працювало» недостатній. |
| BUILD DIFFERENCE | Exact hash/compiled symbols/reference graphs/deployed variant пояснюють різницю; відрізняти metadata-only SHA difference від executable difference. |
| VALHEIM VERSION ISSUE | Exact native game version/assembly identity та controlled comparison або primary native evidence пов'язують проблему з game change. Не присвоювати за здогадкою. |
| PRE-EXISTING BUG | Те саме порушення підтверджено prior reference/source/runtime відповідного scope; structural proof не перетворювати на live impact. |
| STALE DOC/TEST | Assertion/description не відповідає current approved contract/build; потрібен targeted comparison. Помилкове очікування не виправляти gameplay. |
| TEST ERROR | Непридатний host/setup/permissions/state/observer або неправильна test expectation; зберегти raw result і reason. |
| DESIGN PENDING | Нема approved observable behavior/decision. Case без execution залишається UNTESTED. |
| UNTESTED | Нема достатнього current matching-case evidence або attribution не встановлена. Вказати exact missing evidence. |

5. PASS/FAIL/UNTESTED by case and dimension; classification separately; comparison to pre-migration evidence if migration attribution claimed.
